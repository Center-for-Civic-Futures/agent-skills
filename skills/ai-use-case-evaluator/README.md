# AI Use Case Evaluation Skill

This skill provides an interactive AI-powered version of [AI-Ready: An Evaluation Guide for Health and Human Services](https://digitalgovernmenthub.org/wp-content/uploads/2024/12/CPSAI-AI-Ready-An-Evaluation-Guide-for-Health-and-Human-Services-Agencies.pdf).

The tool lets you upload project planning and design documents, asks questions to fill in any knowledge gaps, and then generates a scorecard with feedback and suggested questions along 4 dimensions:

1. Value proposition
2. Technical feasibility
3. Bias and ethical considerations
4. Responsible use and deployment

Contact [Center for Civic Futures](https://www.centerforcivicfutures.org/contact) for more information.
