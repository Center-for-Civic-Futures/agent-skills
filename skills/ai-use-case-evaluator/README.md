# AI Use Case Evaluation Skill

This tool helps government health and human services teams evaluate and refine early-stage AI proposals. Using [AI-Ready: An Evaluation Guide for Health and Human Services](https://digitalgovernmenthub.org/wp-content/uploads/2024/12/CPSAI-AI-Ready-An-Evaluation-Guide-for-Health-and-Human-Services-Agencies.pdf) as a reference, it shares advice tailored to your project through a conversational AI interface.

The tool lets you upload project planning and design documents, and then asks questions to fill in any knowledge gaps. Finally, it generates a scorecard with feedback and suggested questions along 4 dimensions:

1. Value proposition
2. Technical feasibility
3. Bias and ethical considerations
4. Responsible use and deployment

Each of these focus areas gets a simple to understand green, yellow, or red rating along with actionable advice and further questions to ask. It turns abstract “responsible AI” principles into recommendations that teams can use to improve designs or vendor requirements. 


## Installation

Check your AI app for instructions on how to install the skill or [these instructions](../../INSTALL.md), then 
start the experience with the prompt like, "Help me evaluate my AI use case."
